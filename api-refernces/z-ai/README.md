## 핵심 문서

### 1. [소개](./introduction.md)
Z.ai API의 기본 개념, 주요 특징, 지원되는 기능에 대한 개요를 제공합니다.

### 2. [API 엔드포인트](./api-endpoint.md)
기본 API 엔드포인트 URL, 버전 관리, 지원되는 프로토콜에 대한 정보를 포함합니다.

### 3. [인증](./authentication.md)
API 키 발급, Bearer 토큰 인증, 보안 관행, SDK를 통한 인증 방법을 설명합니다.

### 4. [플레이그라운드](./playground.md)
웹 기반 API 테스트 도구 사용법, 주요 기능, 브라우저 호환성에 대한 정보를 제공합니다.

### 5. [사용 예제](./call-examples.md)
Python, JavaScript, Java, cURL 등 다양한 프로그래밍 언어에서의 API 호출 예제를 포함합니다.

## 지원되는 프로그래밍 언어

Z.ai는 다음 프로그래밍 언어를 위한 공식 SDK를 제공합니다:

- Python
- JavaScript/Node.js
- Java
- cURL (직접 HTTP 호출)

## API 기능

- 챗봇 대화
- 텍스트 생성
- 임베딩
- 모델 관리
- 기타 AI 서비스
