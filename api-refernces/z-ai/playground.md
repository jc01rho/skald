# Z.ai API 플레이그라운드

## 개요

Z.ai API 플레이그라운드는 웹 기반 인터페이스로, 개발자가 코드를 작성하지 않고도 API 기능을 테스트하고 탐색할 수 있도록 지원합니다.

## 접근 방법

플레이그라운드는 Z.ai 개발자 대시보드에서 접근할 수 있습니다:

1. Z.ai 계정에 로그인
2. API 문서 섹션에서 "Playground" 탭 선택
3. 웹 인터페이스를 통해 API 테스트

## 주요 기능

### 실시간 API 테스트

- API 요청과 응답을 실시간으로 확인
- 다양한 파라미터 조합 테스트
- 오류 메시지 즉시 확인

### 코드 생성

- 테스트한 API 호출에 대한 코드 예제 자동 생성
- 다양한 프로그래밍 언어 지원 (Python, JavaScript, Java 등)
- 클립보드로 코드 복사 기능

### 요청 기록

- 이전 API 호출 기록 저장
- 성공 및 실패한 요청 분석
- 테스트 시나리오 재사용

## 지원되는 API 엔드포인트

플레이그라운드에서는 다음 API 엔드포인트를 테스트할 수 있습니다:

- 챗봇 대화 (`/chat/completions`)
- 텍스트 생성
- 임베딩 생성
- 모델 정보 조회

## 인증 설정

플레이그라운드에서 API 키를 안전하게 설정할 수 있습니다:

1. 인증 탭에서 API 키 입력
2. 키 유효성 자동 확인
3. 세션 동안 키 유지 (브라우저 로컬 스토리지에 저장)

## 고급 기능

### 파라미터 자동 완성

- 일반적인 파라미터에 대한 자동 완성 제안
- API 문서와 연동된 도움말
- 필수 및 선택적 파라미터 구분

### 응답 분석

- JSON 응답 구조화된 뷰
- 응답 시간 및 크기 정보
- 응답 형식 유효성 검사

### 요청 내보내기/가져오기

- 테스트한 API 호출을 cURL 명령어로 내보내기
- 테스트 시나리오를 JSON 파일로 저장/로드
- 팀원과 테스트 결과 공유

## 사용 팁

1. **간단한 테스트 시작**: 기본 파라미터로 간단한 API 호출부터 시작하세요
2. **단계적 복잡성 증가**: 성공적인 테스트 후 점차적으로 파라미터를 추가하세요
3. **오류 분석**: 실패한 요청의 오류 메시지를 주의 깊게 분석하세요
4. **문서와 함께 사용**: 플레이그라운드 테스트 결과와 API 문서를 함께 참조하세요

## 브라우저 호환성

플레이그라운드는 최신 웹 브라우저와 호환됩니다:

- Chrome (최신 버전)
- Firefox (최신 버전)
- Safari (최신 버전)
- Edge (최신 버전)
