# Z.ai API 소개

Z.ai API는 다양한 프로그래밍 언어와 개발 환경을 지원하는 표준 HTTP API 인터페이스를 제공하며, SDK도 함께 제공됩니다.

## 개요

Z.ai 플랫폼과 상호작용하기 위해 사용할 수 있는 RESTful API를 설명하는 API 레퍼런스입니다.

## 주요 특징

- 표준 HTTP API 인터페이스
- 다중 프로그래밍 언어 지원
- 다양한 개발 환경 호환성
- 공식 SDK 제공

## API 기본 정보

Z.ai API는 RESTful 아키텍처를 기반으로 하며, 표준 HTTP 메소드를 사용하여 통신합니다. JSON 형식으로 요청과 응답을 처리하며, 인증을 위해 API 키가 필요합니다.

## 시작하기

Z.ai API를 사용하려면 다음 단계를 따르세요:

1. API 키 발급
2. 인증 설정
3. API 엔드포인트 확인
4. 첫 번째 API 호출

## 지원되는 기능

- 챗봇 대화
- 텍스트 생성
- 모델 관리
- 기타 AI 서비스
